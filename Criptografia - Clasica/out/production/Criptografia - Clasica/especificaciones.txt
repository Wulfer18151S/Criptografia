Se requiere desarrollar un programa de encriptado o cifrado clásico. El programa puede incluir una interfaz gráfica si es necesario.

Debe permitir mostrar el texto original que se desea cifrar y, posteriormente, visualizar el texto cifrado en un apartado diferente.

El sistema debe contar con botones para seleccionar distintos métodos de cifrado clásico, entre los cuales se incluyen:

Cifrado César
Cifrado Atbash
Cifrado Vigenère
Cifrado Rail Fence
Cifrado Playfair

Cada método debe incluir una breve descripción que explique su funcionamiento.

Además, el programa debe permitir tanto cifrar como descifrar el texto utilizando cada uno de los métodos mencionados.
